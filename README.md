# 従業員マスター

Excel 365（Windows デスクトップ版）向けの、従業員と所属の履歴を管理するマクロ付きブックです。毎月全員を入力し直さず、新規入社・異動などの変更だけを登録します。

**[従業員マスター.xlsm をダウンロード](https://github.com/hinapoooon-create/Excel/raw/refs/heads/claude/upload-w43gq3/従業員マスター.xlsm)**

公開リポジトリのため、ダウンロードに GitHub へのログインは不要です。架空の従業員・店舗によるサンプルを含みます。

2026-09-15：シート4（一括登録）の読み込みエラーの原因となるXML要素順序を修正しました。修正前のエラーを公式スキーマで再現し、修正後は全38個のSpreadsheetMLパーツが検証を通過しました。[修正・検証結果](XML_CHECK.md)

## 基本の使い方

1. ダウンロードしたファイルを Windows の Excel 365 で開きます。VBAを使用するため、Excel Onlineでは操作できません。
2. 「ホーム」から「一括登録」を開きます。
3. 各行の「登録区分」で「新規」「異動」などを選び、必要な欄を入力・貼り付けします。新規と異動を同じ一覧でまとめて登録できます（1回200行）。
4. 「まとめて登録」を押し、件数を確認します。入力不備がある場合は、1件も登録せず「確認結果」に理由を表示します。
5. ホームで集計対象月を選び、「月別表を更新」を押します。

通常は氏名・店舗名・役職名で選択します。従業員IDは新規登録時だけ入力します。同姓同名は「識別補助」で区別できます。補助項目の表示ボタンで、識別補助・ふりがな・初期状態・備考を表示できます。

同じ一覧に新規登録する人の変更を入れる場合も、氏名（識別補助がある場合は `氏名 (識別補助)`）で指定できます。行の順番は問いません。異動と役職変更はそれぞれ1行に分けます。

## 反映ルール

| 登録内容 | 月別表への反映 |
| --- | --- |
| 新規入社 | 指定した反映開始月から |
| 店舗異動 | 異動日である月の1日から。過去月は元の店舗 |
| 役職変更 | 指定した反映開始月から |
| 退職・休職・出向 | 発生日の翌月1日から対象外 |
| 復職・出向から復帰 | 戻った日の翌月1日から再び対象 |

退職月は対象に残ります。「月別従業員」の「実績加算最終日」を使い、実績データと結合する側で退職日より後の実績を除外してください。本ブックは従業員・目標のマスターであり、実際の売上明細は含みません。

## 初回設定と保守

保守担当がホームの設定画面で、店舗・ブロック・役職・ポイント・集計開始月を自社用に変更してください。ブック全体の目標方式は「個人目標を合算」または「店舗に直接入力」のどちらかに設定します。

個人方式では、各人の役職ポイントを合計した値が店舗目標になります。店舗方式では「店舗目標入力」で月・店舗ごとの値を登録します。過去月の訂正は、保守担当が元の台帳を修正してから月別表を更新します。

「本番利用の準備」は従業員などのサンプルを消去します。実行前のコピーを同じフォルダーに保存します。店舗・ブロック・役職の設定は残るため、自社用への設定変更が必要です。シート保護用パスワードは `master` です。

ダウンロードしたマクロがブロックされる場合は、ファイルの入手元と内容を確認したうえで、[Microsoftの案内](https://learn.microsoft.com/ja-jp/deployoffice/security/internet-macros-blocked)に沿って対象ファイルのブロック解除を行ってください。
